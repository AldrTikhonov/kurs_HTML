Основные теги

< h1 >

align=

    left - выравнивание по левому краю
    center - выравнивание по центру
    right - выравнивание по правому краю
    justify - выравнивание по ширине страницы

< img >

    src="URL" - Адрес загружаемого рисунка
    align="bottom | left | middle | right | top" - Способ выравнивания изображения в документе
    title="текст" - Описание изображения, появляемое при наведении курсора мыши
    border="толщина рамки" - Устанавливает толщину рамки вокруг изображения. Чтобы убрать рамку нужно поставить значение 0
    height="высота" - Высота рисунка
    width="ширина" - Ширина рисунка
    hspace="отступ по горизонтали" - Задает величину отступа по горизонтали
    vspace="отступ по вертикали" -Задает величину отступа по вертикали
